# منصة ركز — إدارة القضايا

منصة **ركز النظامية للمحاماة والاستشارات القانونية** لإدارة القضايا والاستشارات والمالية وصياغة المستندات، مع مساعد قانوني ذكي (Claude).

## ما تقدمه المنصة

- **لوحة تحكم**: القضايا المنظورة، جلسات الأسبوع، المتأخرات، حمل العمل لكل محامٍ.
- **القضايا**: ملف كامل لكل قضية، وسجل إجراءات تلقائي، ومرفقات يقرؤها المساعد فيستخرج المواعيد والمتطلبات ويتحقق من جهة الاختصاص.
- **الإسناد**: يُسنده المدير فقط، ولا تنتقل القضية إلا بعد قبول المحامي.
- **الاستئناف والنقض والالتماس**: حاسبة مهل الاعتراض، ولوائح يصوغها المساعد بأسبابها النظامية.
- **مركز ناجز**: يسحب مستجدات القضايا من ناجز (نص منسوخ، رسائل SMS، صكوك الأحكام ومحاضر الجلسات، لقطات شاشة، أو زر «إرسال إلى ركز» في المتصفح)، فيستخرج المساعد الجلسات والأحكام والمهل ويطابقها مع القضايا برقم ناجز، ولا يُحفظ شيء قبل اعتمادك. الربط الرسمي عبر واجهات وزارة العدل (developers.najiz.sa) يتطلب حساب مطور واعتماد الوزارة.
- **المهام والتذكيرات** مرتبة بالأولوية حسب مواعيد التسليم.
- **الاستشارات**: تسجيل السؤال وإرفاق مستنداتها (يقرؤها المساعد)، مسودة رأي قانوني، تحويلها إلى قضية.
- **المالية**: مطالبات بضريبة 15%، دفعات مع إرفاق إيصال السداد (يطّلع عليه المدير فقط)، مصروفات، ذمم العملاء.
- **الإرسال للعميل عبر واتساب أو البريد الإلكتروني**: المطالبات المالية والمستندات والآراء القانونية وتقارير المستجدات، مع مشاركة ملف Word مباشرة من الجوال، ويُسجَّل كل إرسال في ملف القضية.
- **الصياغة**: عقود من النموذج الأساسي، عروض أتعاب، لوائح ومذكرات، وتصدير Word بترويسة الشركة.
- تصميم فاتح مع وضع داكن، ومهيأ للجوال.

## التشغيل (مرة واحدة، نحو 15 دقيقة)

المنصة صفحة ثابتة على **GitHub Pages**، وبياناتها وملفاتها وتسجيل الدخول على **Supabase** (الخطة المجانية تكفي للبداية)، والمساعد الذكي عبر **Anthropic API**.

### 1) قاعدة البيانات — Supabase

1. أنشئ حسابًا ومشروعًا جديدًا على [supabase.com](https://supabase.com) (اختر منطقة قريبة، مثل Frankfurt أو Mumbai).
2. من **SQL Editor** ← New query: الصق محتوى الملف [`supabase/schema.sql`](supabase/schema.sql) واضغط **Run**.
   ينشئ جدول البيانات، وصلاحيات الأعضاء، والتحديث الفوري، ومخزن الملفات الخاص `files`.
4. من **Authentication ← URL Configuration**: ضع رابط المنصة على GitHub Pages في **Site URL** (مثل `https://USERNAME.github.io/rakz/`).
5. من **Authentication ← Sign In / Providers**: فعّل **Allow new users to sign up** وأوقف **Confirm email** (خدمة البريد المجانية في Supabase لا ترسل إلا لأعضاء فريق المشروع).
6. الحماية: لا تُفتح البيانات إلا لبريد مسجل على عضو نشط في «فريق العمل»، فمن ينشئ حسابًا ببريد غير مضاف لا يرى شيئًا.

**إضافة عضو:** أضفه في «فريق العمل» ببريده، ثم اضغط «دعوة» لترسل له الرابط عبر واتساب؛ يفتحه ويختار «إنشاء حساب» بنفس البريد.

### 2) المساعد الذكي — اختياري (مدفوع)

المنصة تعمل كاملة دونه: اللوائح والآراء القانونية تُنشأ من نماذج بهيكلها النظامي وبيانات القضية، والفراغات مظللة لتعبئتها. لتفعيله لاحقًا نفّذ ما يلي ثم اجعل `aiEnabled: true` في `docs/config.js`.


1. أنشئ مفتاح API من [platform.claude.com](https://platform.claude.com) (Settings ← API Keys).
2. في Supabase: **Edge Functions ← Secrets** ← أضف `ANTHROPIC_API_KEY` بقيمة المفتاح.
3. **Edge Functions ← Deploy a new function ← Via Editor**: سمّها `claude`، والصق محتوى [`supabase/functions/claude/index.ts`](supabase/functions/claude/index.ts)، ثم **Deploy**.
   أبقِ خيار **Verify JWT** مفعّلًا حتى لا يستخدمها إلا الأعضاء.

   أو بسطر الأوامر: `supabase functions deploy claude` بعد `supabase secrets set ANTHROPIC_API_KEY=...`

يستخدم المساعد نموذج `claude-opus-5-5`، مع تفعيل التحويل التلقائي إلى نموذج بديل إذا رفض الطلب لأسباب السلامة.

### 3) ربط الواجهة

عدّل الملف [`docs/config.js`](docs/config.js) (من GitHub مباشرة بزر القلم):

```js
window.RAKZ_CONFIG = {
  supabaseUrl: "https://xxxx.supabase.co",   // Project Settings ← API ← Project URL
  supabaseAnonKey: "eyJ...",                 // Project Settings ← API ← anon public
  ownerEmail: "you@example.com",             // اختياري: بريد المدير الرئيسي
};
```

المفتاح العام (anon) آمن للنشر، فكل قراءة وكتابة محمية بسياسات قاعدة البيانات ولا تُقبل إلا من عضو مسجّل. **لا تضع مفتاح Anthropic في هذا الملف أبدًا.**

### 4) أول استخدام

1. ادخل ببريدك، ثم من **فريق العمل** أنشئ ملفك واجعل صفتك **مدير** (تمنح صلاحية الإسناد).
2. أضف أعضاء الفريق، وكل عضو يختار اسمه من «تعمل باسم» أسفل القائمة.
3. من **الإعدادات** أكمل بيانات الشركة: السجل التجاري، الترخيص، الرقم الضريبي، الآيبان.

## هيكل المستودع

| المسار | المحتوى |
|---|---|
| `docs/` | الموقع المنشور على GitHub Pages (`index.html` مبني، و`config.js` للربط) |
| `src/` | مصدر الواجهة: `core.js` البيانات والتنقل، `views.js` الصفحات، `ai.js` المرفقات والتحليل، `docengine.js` محرك المستندات وWord، `docs.js` الصياغة، `extra.js` الاعتراضات والمالية والاستشارات والتقارير |
| `standalone/shim.js` | طبقة الربط بـ Supabase (قاعدة البيانات، الملفات، الدخول، المساعد) |
| `supabase/` | مخطط قاعدة البيانات ووظيفة المساعد |
| `assets/` | شعار الشركة |
| `build.py` | يبني `docs/index.html` من المصدر: `python3 build.py` |

## ملاحظات

- المطالبات المالية مستندات مطالبة، وليست فواتير ضريبية إلكترونية متوافقة مع منصة «فاتورة».
- مخرجات المساعد مسودات يراجعها المحامي قبل الاعتماد.
- المهل النظامية تُحتسب للتذكير، ويجب التحقق منها ومن العطل الرسمية.

## المكتبة النظامية

يقرأ المساعد المواد ذات الصلة من «المكتبة النظامية» قبل كل تحليل أو صياغة، ويُحيل إليها باسم النظام ورقم المادة.

- **المكتبة الرسمية**: 75 نظامًا ولائحة (أكثر من 6,000 مادة) مرتبة شجريًا: كل نظام رئيسي وتحته لوائحه التنفيذية وقواعده وأدلته الإجرائية. الأنظمة من هيئة الخبراء بمجلس الوزراء (laws.boe.gov.sa)، واللوائح والقواعد من البوابة القانونية لوزارة العدل (laws.moj.gov.sa)، وتُنشر في `docs/laws/core.json`. تُستورد من زر «استيراد المكتبة الرسمية».
- يقرأ المساعد النظام ولائحته معًا، ويُحيل إلى اللائحة منسوبة إلى نظامها (مثل: المادة 3/1 من اللوائح التنفيذية لنظام المرافعات الشرعية)، ويراعي حالة النفاذ (مثل نظام التنفيذ 1447هـ الذي يُعمل به من 2026-10-28م).
- **تحديثها** عند صدور تعديل: `python3 -X utf8 tools/law_library.py` ثم ارفع الملف واضغط زر الاستيراد مرة أخرى؛ يستبدل النص القديم. لإضافة لائحة جديدة أضف معرّفها تحت نظامها في قائمة `FAMILIES` داخل الأداة.
- المواد المعدّلة تحمل نصها النافذ مع **كل تعديل مسجل** عليها (رقم المرسوم أو القرار وتاريخه)، والمواد الملغاة معلّمة «مادة ملغاة».
- أي نظام أو لائحة أخرى تُضاف من زر «إضافة نظام» بملف PDF أو Word أو نص ملصوق.

## الصلاحيات والمالية

- **الهوية** هي حساب الدخول: يُعرف العضو ببريده المسجل في «فريق العمل»، ولا يمكن العمل باسم عضو آخر.
- **صفة «مدير» وحدها**: الإسناد، والمالية (المطالبات، المدفوعات، المصروفات، القيود، العقود، عروض الأتعاب)، وإدارة الفريق والإعدادات. تُفرض في قاعدة البيانات (سياسات RLS ومشغلات) لا في الواجهة فقط.
- **أتعاب المحامي**: يقترح المحامي أتعاب قضاياه واستشاراته، وتبقى «بانتظار اعتماد المدير»، ولا يعدّلها بعد الاعتماد ولا يرى أتعاب غيره. اعتماد المدير يجعلها أتعاب القضية المعتمدة.
- **القيود المحاسبية (قيد مزدوج)**: كل مطالبة ودفعة ومصروف يُرحَّل قيدها آليًا على دليل حسابات ثابت (1100 الصندوق والبنك، 1200 ذمم العملاء، 2100 ضريبة القيمة المضافة، 2200 دفعات مقدمة، 3100 جاري الشركاء، 4100/4200 الإيرادات، 5100/5200 المصروفات). القيد المرحّل لا يُعدَّل ولا يُحذف، وأي تعديل على الحركة يرحّل قيد تسوية بالفرق. التقارير: دفتر القيود، ميزان المراجعة، كشف حساب العميل (مع تنزيل CSV)، والقيود اليدوية المتوازنة.
